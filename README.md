## Про проєкт

MeetMateBot — це Telegram-бот, який допомагає планувати зустрічі, керувати учасниками та надсилати нагадування. Проєкт побудований за принципами чистої архітектури, що забезпечує розділення відповідальностей, тестованість і легку розширюваність.

## Структура рішення

| Проєкт | Призначення |
|---|---|
| MeetMateBot.Domain         | Доменні сутності та бізнес-правила |
| MeetMateBot.Application    | Сценарії використання, інтерфейси, логіка застосунку |
| MeetMateBot.Infrastructure | Зовнішні інтеграції (БД, Telegram API, сервіси) |
| MeetMateBot.Bot            | Точка входу, хендлери Telegram-бота |
| MeetMateBot.Tests          | Юніт- та інтеграційні тести |

##  Технології

- C# / .NET
- Telegram Bot API
- Clean Architecture
- Модульне тестування (xUnit / NUnit)

## Можливості

- Створення та планування зустрічей
- Керування учасниками
- Нагадування про зустрічі
- Розширювана архітектура для додавання нових функцій

## Встановлення та запуск
